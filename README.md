# Udemy Clone

A responsive Udemy-inspired course website built with HTML, CSS, and JavaScript.

## Live Demo

**Live Website:** [View Udemy Clone](https://udemy-clone-19wt.onrender.com)

## GitHub Repository

https://github.com/Thamizh-25/udemy-clone

## Features

- Responsive navigation and category menu
- Course search and category filtering
- Sorting by ratings, reviews, and price
- Add topic suggestions
- Recommended and popular courses
- Responsive desktop, tablet, and mobile layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Deployment

Hosted on Render as a static website.

## Disclaimer

This is an educational front-end project inspired by an online learning platform and is not affiliated with Udemy.
